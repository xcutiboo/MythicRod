# MythicRod

> Custom fishing drops, biome rules, rod tiers, an in-game GUI editor,
> statistics, and a small public API. Built for Paper and Folia.

## What it does

Replace vanilla fishing rewards with weighted, biome-scoped loot tables you
configure in `drops.yml`. The plugin reloads atomically, exposes its catalog
through a public API, and ships with an in-game GUI for editing drops,
toggling features, switching languages, and inspecting statistics.

## Features

- Weighted drop tables with tier markers (`common`, `uncommon`, `rare`,
  `legendary`).
- Biome-specific drops with optional permission gates per drop.
- Custom rods with a persistent tier stored in PersistentDataContainer.
- Per-player statistics and a leaderboard, persisted to `statistics.yml`.
- Brigadier-style commands with live-state suggestions. Only real drop IDs,
  categories, biomes, and player names show up in autocomplete.
- GUI hub for config, drops, rods, stats, and a language picker.
- Folia handoffs in the listener, scheduler service, and reward delivery
  path.
- Public API published through the Bukkit ServicesManager. Register external
  drop providers, query stats, listen for reward and catch events.
- Bundled languages: `en_US` and `ja_JP`. Crowdin is wired up for the rest.
  Unknown locales fall back to a neutral language head in the GUI.

## Install

1. Drop `MythicRod-Paper-<version>.jar` into `plugins/`.
2. Start the server once.
3. Edit `plugins/MythicRod/config.yml` and `drops.yml`.
4. `/mythicrod reload`.

Nexo integration is optional and only kicks in if you use `nexo:*`
identifiers in `drops.yml`.

## Commands

- `/mythicrod` opens the main GUI.
- `/mythicrod config <setting> <value>` (alias `/mythicrod settings`) edits
  feature toggles, delivery mode, language, and the stats save interval.
- `/mythicrod give <player> <tier>` hands out a tiered rod.
- `/mythicrod stats [player]`, `/mythicrod top [limit]`, `/mythicrod drops`,
  `/mythicrod reload`, `/mythicrod debug`, `/mythicrod validate`,
  `/mythicrod testroll [biome] [count]`, `/mythicrod rod inspect`.

Full reference: [docs](https://xcutiboo.github.io/MythicRod/commands).
