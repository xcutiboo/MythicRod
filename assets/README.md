# Assets

Brand and layout art for README, docs site, and Hangar.

- `icon.svg` — official plugin icon with dark panel background. Used as the
  square brand mark on listings and store pages.
- `icon-transparent.svg` — same emblem without the panel, for embedding on
  the README header and other dark surfaces.
- `banner.svg` — wide title banner used at the top of the README and the
  GitHub Pages site.
- `divider.svg` — thin gold gradient rule with a centred diamond accent.
- `divider-feature.svg` — heavier divider with a reel-ring motif, used
  between major sections.
