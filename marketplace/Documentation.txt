[SIZE=5][B][COLOR=#f6c45f]Step-by-Step Setup[/COLOR][/B][/SIZE]
[SIZE=4][COLOR=#23313f][LIST=1]
[*]Download MythicRod.jar from the resource page.
[*]Place it into your server's [B]plugins/[/B] folder.
[*]Start or restart your Minecraft server.
[*]Configs generate in [B]plugins/MythicRod/[/B].
[*]Edit [B]config.yml[/B] and [B]drops.yml[/B] to customize.
[*]Run [B]/mythicrod reload[/B] to apply changes.
[*]Test fishing and verify custom drops work.
[/LIST][/COLOR][/SIZE]

[SIZE=5][B][COLOR=#f6c45f]Main Settings (config.yml)[/COLOR][/B][/SIZE]
[CODE]# Plugin prefix
prefix: '&6&l<MythicRod> &r'

# Visual effects
use-sounds: true
use-particles: true

# Core features
track-statistics: true
enable-biome-specific-drops: true
use-permissions: false

# Performance
stats-save-interval: 600
hook-cleanup-interval: 300

# Debug
debug-mode: false[/CODE]

[SIZE=5][B][COLOR=#f6c45f]Drop Configuration (drops.yml)[/COLOR][/B][/SIZE]

[SIZE=4][B][COLOR=#9b7bdc]Global Drops[/COLOR][/B] — Available to all players[/SIZE]
[CODE]drops:
  global:
    - 'DIAMOND,5,1'        # Material, Weight, Amount
    - 'IRON_INGOT,30,1'
    - 'GOLD_INGOT,20,1'
    - 'EMERALD,15,1'[/CODE]

[SIZE=4][B][COLOR=#9b7bdc]Rare Drops[/COLOR][/B] — Requires mythicrod.drops.rare[/SIZE]
[CODE]  rare:
    - 'ANCIENT_DEBRIS,3,1'
    - 'NETHERITE_SCRAP,5,1'
    - 'DIAMOND_BLOCK,1,1'
    - 'NETHER_STAR,1,1'[/CODE]

[SIZE=4][B][COLOR=#9b7bdc]Legendary Items[/COLOR][/B] — Custom items with properties[/SIZE]
[CODE]  legendary:
    excalibur:
      material: NETHERITE_SWORD
      chance: 1
      amount: 1
      name: '&b&lExcalibur'
      lore:
        - '&7A legendary sword'
      enchantments:
        sharpness: 10
        unbreaking: 5
      glowing: true
      permission: mythicrod.drops.legendary[/CODE]

[SIZE=4][B][COLOR=#9b7bdc]Biome-Specific[/COLOR][/B] — Different loot per biome[/SIZE]
[CODE]biome-drops:
  ocean:
    - 'PRISMARINE_CRYSTALS,20,1'
    - 'HEART_OF_THE_SEA,5,1'
  desert:
    - 'GOLD_NUGGET,30,3'
    - 'EMERALD,10,1'
  jungle:
    - 'COCOA_BEANS,30,2'
    - 'BAMBOO,40,3'
  frozen:
    - 'PACKED_ICE,25,1'
    - 'BLUE_ICE,5,1'[/CODE]

[SIZE=5][B][COLOR=#f6c45f]Weight System[/COLOR][/B][/SIZE]
[SIZE=4][COLOR=#23313f]Higher weight = higher chance. Weights are relative proportions.[/COLOR][/SIZE]
[CODE]DIAMOND (5)     -> 5/100 = 5%
IRON (30)       -> 30/100 = 30%
GOLD (20)       -> 20/100 = 20%
EMERALD (15)    -> 15/100 = 15%
NETHERITE (1)   -> 1/100 = 1%
Total: 100      = 100%[/CODE]

[SIZE=5][B][COLOR=#f6c45f]Drop Selection Process[/COLOR][/B][/SIZE]
[SIZE=4][LIST=1]
[*][COLOR=#23313f]Player casts fishing rod.[/COLOR]
[*][COLOR=#23313f]Catch event fires.[/COLOR]
[*][COLOR=#23313f]Plugin checks biome location.[/COLOR]
[*][COLOR=#23313f]Chooses drop category (global/rare/biome).[/COLOR]
[*][COLOR=#23313f]Picks a drop by weight.[/COLOR]
[*][COLOR=#23313f]Permission check if enabled.[/COLOR]
[*][COLOR=#23313f]Generates item (name, lore, enchants, glow).[/COLOR]
[*][COLOR=#23313f]Gives item, plays sounds/particles.[/COLOR]
[*][COLOR=#23313f]Updates statistics.[/COLOR]
[/LIST][/SIZE]

[SIZE=4][B][COLOR=#f6c45f]Biome Detection[/COLOR][/B][/SIZE]
[SIZE=4][COLOR=#23313f]MythicRod detects the fishing biome and applies the matching drop table; it falls back to global drops if none are configured.[/COLOR][/SIZE]

[SIZE=4][COLOR=#23313f][B]Drops not working?[/B] Check drops.yml syntax, then run /mythicrod reload and review console.[/COLOR][/SIZE]
[SIZE=4][COLOR=#23313f][B]Players missing rare drops?[/B] Grant mythicrod.drops.rare and set use-permissions: true.[/COLOR][/SIZE]
[SIZE=4][COLOR=#23313f][B]GUI not opening?[/B] Confirm mythicrod.gui permission and server version 1.21+; reload if needed.[/COLOR][/SIZE]
[SIZE=4][COLOR=#23313f][B]Stats not saving?[/B] Enable track-statistics and ensure the server can write files.[/COLOR][/SIZE]
[SIZE=4][COLOR=#23313f][B]Config changes not applying?[/B] Always run /mythicrod reload after edits.[/COLOR][/SIZE]
[SIZE=4][COLOR=#23313f][B]Console errors?[/B] Enable debug-mode, check YAML, and verify material names.[/COLOR][/SIZE]
