# Contributing

## Build and test

```bash
./gradlew build
```

The plugin jar is produced under `build/libs/`.

## Pull requests

- Match the existing code style.
- Add tests when changing logic.
- Run `./gradlew build` locally before opening a pull request.
- Keep commits small and focused.

## Reporting bugs

Open a GitHub issue with steps to reproduce, the plugin version, and the
server build (Paper or Folia and the exact version string).
