# MythicRod Changelog

All notable changes to the MythicRod plugin will be documented in this file.

## [2.0.0] - 2025-04-14

### Added

- Complete rewrite with a modern modular architecture
- Biome-specific fishing drops system
- Permission-based drop categories
- Player fishing statistics tracking
- Advanced item customization (names, lore, enchantments, glowing effects)
- In-game commands for management and statistics
- Developer API for third-party plugin integration
- Sound and particle effects for immersive fishing experience
- Automatic statistics saving
- Comprehensive documentation

### Changed

- Improved configuration system with multiple specialized files
- Enhanced drop system with weighted probabilities
- Optimized hook tracking to prevent exploitation
- Updated to latest Paper API standards
- Better error handling and logging
- More efficient memory usage

### Fixed

- Fixed memory leaks from untracked fishing hooks
- Resolved concurrency issues with hook tracking
- Improved compatibility with other plugins

## [1.0.1] - Initial Release

- Basic fishing replacement system
- Simple drop configuration
- Anti-exploitation measures
