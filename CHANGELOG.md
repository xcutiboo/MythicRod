# Changelog

## [1.0.1] - 2025-12-14

- Fixed fishing edge case where waiting after a bite could bypass custom drops and return vanilla fish by restoring hook state and cleaning it up correctly.

## [1.0.0] - 2025-12-13

Initial release with:

- Custom fishing drop system
- Biome-specific drops
- Permission-based categories
- Statistics tracking and leaderboards
- Item customization (names, lore, enchantments, glowing)
- In-game GUI menus
- Multi-language support (English, Japanese)
- Sound and particle effects
- Developer API
